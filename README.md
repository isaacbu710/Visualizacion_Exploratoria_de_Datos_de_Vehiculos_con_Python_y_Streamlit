# Visualización Exploratoria de Datos de Vehículos con Python y Streamlit
🔹 Descripción
Proyecto de visualización de datos interactiva que permite explorar un dataset de vehículos mediante un dashboard web. Incluye análisis exploratorio de datos (EDA), visualizaciones interactivas y despliegue en la nube para acceso público.

🔹 Tecnologías Utilizadas

Lenguajes y librerías: Python, Pandas, Plotly Express, Streamlit
Entorno y despliegue: Render, GitHub, virtualenv
Metodologías: Análisis Exploratorio de Datos (EDA), dashboards interactivos, data storytelling

🔹 Funcionalidades y Responsabilidades
Configuración de entorno virtual e instalación de dependencias (requirements.txt)
Limpieza y preprocesamiento de datos con Python y Pandas
Exploración de datos mediante notebooks en Jupyter (EDA.ipynb)
Creación de dashboard web con Streamlit que incluye:
Gráficos interactivos (histogramas, scatter plots)
Filtros mediante botones y casillas de verificación
Despliegue automático en Render mediante integración con GitHub

🔹 Resultados / Impacto
Generación de insights claros y visuales sobre los datos de vehículos
Facilita la exploración interactiva para usuarios sin conocimientos de programación
Aplicación accesible públicamente vía URL, cumpliendo buenas prácticas de documentación y estructura de repositorio

🔹 Archivos Incluidos
EDA.ipynb: Notebook con análisis exploratorio de datos
app.py: Código principal del dashboard interactivo
requirements.txt: Dependencias necesarias para ejecutar la aplicación
vehicles_us.csv: Dataset de vehículos utilizado en el proyecto
